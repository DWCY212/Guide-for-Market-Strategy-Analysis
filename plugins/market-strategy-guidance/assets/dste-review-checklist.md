# DSTE 市场战略审查清单

这份清单把转会诊市域医疗治理报告中暴露的常见问题抽象成可复用检查项。它不是对任何具体项目的事实结论。

## 先判定报告能支持什么

报告可能支持战略方向、初步客群筛选、进入假设或正式经营预算，这四种结论的证据要求不同。没有可复算的市场空间、采购闭环、案例归因和交付经济性时，不应把报告评为经营预算依据。

## 高风险信号

- 同一报告出现多个城市/机构基数，但没有分层公式和排除规则。
- 用市场份额、获取目标或预期收入乘市场基数，直接命名为 TAM/SAM。
- 用一个样板项目的效果数字证明全国复制，却没有验收原件、统计口径和因果边界。
- 把“竞品公开资料未发现”写成“竞品不具备”。
- 把治理咨询、平台软件、人工运营、专家服务和集成总包合并为一个产品价格。
- 有目标城市和年度目标，却没有商机阶段、客单价、转化率和交付产能。
- 规划期、市场释放期、建设期、收入确认期和续费期混用。
- 正文依赖图片或外部附件，读者无法复算关键表格。

## 最小修订表

| 输出 | 最低要求 |
| --- | --- |
| 决策摘要 | 进入判断、优先客群、时间窗口、主要风险、结论等级 |
| 市场定义 | 客户、场景、地域、时间、支付/采购口径、排除项 |
| 城市/机构表 | 唯一 ID、分层条件、数量、来源、筛选公式、状态 |
| 市场空间 | TAM、能力 SAM、需求 SAM、SOM、公司收入目标分别计算 |
| 采购闭环 | 采购主体、预算、采购包、验收、周期、续费/扩容 |
| Right to Win | 我方交付事实、结果证据、因果边界、迁移条件、竞品证据 |
| 进入计划 | 目标客户、伙伴、产品包、销售阶段、实施周期、复制门槛 |
| 风险看板 | 指标、阈值、数据源、负责人、复查周期和动作 |
